# AI Roles Assessment

Workmatik tool for marketing leaders to assess 31 marketing roles and 519 activities, and classify each as full automation, augmentation or human only.

Runs entirely in the browser. Nothing is sent or stored. Use Save to download a progress file and Load to resume later.

Live address: https://scottstockwellworkmatik.github.io/ai-roles-assessment/

## Shared IDs and files
Roles have stable IDs (R01 to R31) and activities have stable IDs (A001 to A519). Export Excel produces a file with a "Workmatik data" sheet and a "Selected activities" sheet that other Workmatik tools can load. Save (JSON) and Load also work with older progress files.
